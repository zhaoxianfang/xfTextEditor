简易编辑器示例

这是一个精简配置的富文本编辑器，仅包含最常用的基础按钮（加粗、斜体、列表、链接、图片等）。 配置越少，加载资源越少，性能越好。

提示：简易模式的配置要点是 config.removeButtons 移除大部分按钮，并只启用少量必要的 extraPlugins。

最简配置代码

<script>
    CKEDITOR.replace( 'editor1', {
        language: 'zh-cn',
        width: '100%',
        height: 300,
        // 简易模式：仅启用最基础的图片与占位符插件
        extraPlugins: 'image2,editorplaceholder,divarea',
        // 通过移除按钮来精简工具栏
        removeButtons: 'Subscript,Superscript,Strike,Outdent,Indent,' +
            'Blockquote,CreateDiv,JustifyBlock,Link,Unlink,Anchor,' +
            'TextColor,BGColor,Format,Font,FontSize,Styles'
    } );
</script>

获取 / 设置内容

// 获取编辑器 HTML 内容
var html = CKEDITOR.instances.editor1.getData();

// 设置编辑器内容
CKEDITOR.instances.editor1.setData( '<p>新内容</p>' );

// 监听内容变化
CKEDITOR.instances.editor1.on( 'change', function () {
    console.log( '内容已变化：', this.getData() );
} );
