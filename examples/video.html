视频插入示例

通过 video 插件，可在编辑器中插入 HTML5 <video> 标签， 支持设置 URL、宽高、自动播放、循环、静音、预加载等属性。

配置

XfEditor.replace('editor', {
    extraPlugins: 'video,fakeobjects',
    toolbar: [ [ 'Video' ] ]   // 仅显示视频按钮做演示
});

命令与事件

  • 命令：editor.execCommand('video') 打开视频对话框。
  • 双击已插入的视频占位符可重新编辑。
