上传功能示例

本编辑器提供三种上传入口，均需后端返回统一的 JSON 结构（详见 docs.html 与 php/ 目录）：

入口触发方式对应配置项
图片上传「图像」按钮 / 拖拽图片filebrowserImageUploadUrl
文件上传「上传」按钮filebrowserUploadUrl
拖拽上传将文件拖入编辑区uploadfile 插件（复用 filebrowserUploadUrl）

后端响应格式（成功）

{
  "uploaded": 1,
  "fileName": "example.jpg",
  "url": "https://your-cdn.com/uploads/example.jpg"
}

后端响应格式（失败）

{
  "uploaded": 0,
  "error": { "message": "文件类型不被允许" }
}
完整 PHP 示例与参数说明，请查看项目根目录 php/ 文件夹。
