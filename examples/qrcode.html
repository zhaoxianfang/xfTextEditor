二维码插入示例

yaqr 插件可在编辑器中生成二维码（基于 widget），常用于插入网址名片、跳转链接等。

配置项（config.yaqr）

配置项默认值说明
defQrUrlhttps://weisifang.com/二维码指向的默认网址。
defTargetBlanktrue点击二维码是否新窗口打开。
defQRSize"100px"二维码图片尺寸。
defCellSize6单个码点像素大小。
defMargin10二维码边距。
colorPt / colorBg#000000 / #ffffff码点颜色 / 背景颜色。
borderWidth / borderColor2 / #000000边框宽度 / 颜色。
correctionLevel"Q"纠错级别（L/M/Q/H）。
CKEDITOR.replace('editor', {
    extraPlugins: 'yaqr',
    yaqr: { defQrUrl: 'https://example.com', defQRSize: '120px' }
});
