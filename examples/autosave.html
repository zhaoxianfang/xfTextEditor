自动保存示例

autosave 插件利用浏览器 localStorage 定时缓存编辑器内容， 防止意外刷新 / 关闭导致内容丢失。

配置项（config.autosave）

配置项默认值说明
Savekey自动localStorage 存储键，需保证页面唯一。
delay15内容变化后多少秒执行一次保存。
NotOlderThen1440仅加载多少分钟以内的缓存（默认一天）。
saveOnDestroyfalse编辑器销毁时是否保存。
messageType"notification"提示方式：notification / statusbar / no。
diffType"sideBySide"对比对话框差异展示方式。
autoLoadfalse启动后是否自动恢复缓存内容。
XfEditor.replace('editor', {
    extraPlugins: 'autosave',
    autosave: { delay: 10, messageType: 'notification', autoLoad: true }
});
