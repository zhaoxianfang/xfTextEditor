xfTextEditor 全功能演示

本页是编辑器的最全功能展示页：进入页面即可看到涵盖文字排版、颜色、行高、字号、 字体、列表、表格、图片、链接、代码块、提示框、卡片、时间轴、图表、二维码、音频、视频、字数统计、 自动保存等几乎所有能力的富文本内容。向下滚动页面，可体验工具栏吸附固定效果， 点击工具栏「预览」可查看带完整排版的独立预览页。

再次编辑：在编辑器中双击任意「文字特效」或「段落特效」（提示框 / 卡片 / 时间轴 / 按钮等）， 会像双击图片一样弹出编辑窗口，可修改其内容与样式；也可选中效果后点击工具栏的 「编辑效果」按钮。导出的内容均为自包含 HTML，不依赖任何外部文件即可呈现。
提示：本页所有功能默认离线可用。图片、音频、视频的上传需要配合后端服务 （见 PHP 上传接口）；下拉「文字特效 / 段落特效」可一键插入现代化网页效果。

实时预览与自包含导出

下方内容由上方编辑器实时生成，并内联「基础排版 + 特效」样式后独立呈现—— 即把编辑器内容变成「自包含 HTML」，可脱离任何外部文件直接展示、复制或下载。 这与 XF.getStandaloneCss() 及导出 API 产出的效果完全一致。
刷新预览将当前编辑器内容渲染到下方预览框 复制 HTML复制自包含 HTML 到剪贴板 下载 .html导出为自包含 HTML 文件 新窗口预览打开带完整排版的独立页面

滚动演示区

继续向下滚动本页面，当编辑器工具栏即将被屏幕顶部遮挡时，它会自动「吸附」固定在页面顶部； 向上回滚后则恢复为正常位置。这一行为由 stickytoolbar 插件基于原生 CSS sticky 实现，性能开销极低。

此处填充若干段落以增加页面高度：编辑器在富文本处理、内容过滤、撤销栈管理等方面均已做性能优化， 包括禁用自动 inline 扫描、限制撤销栈深度、去除空段落等，从而在保证功能完整的同时保持流畅响应。

更多使用说明与完整 API 请参阅 开发文档；若需后端上传能力，请查看 PHP 上传接口 页面。
