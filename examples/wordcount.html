字数统计示例

wordcount 插件在编辑器底部状态栏实时显示字数、段落数与字符数。

配置项（config.wordcount）

配置项默认值说明
showParagraphstrue是否显示段落计数。
showWordCounttrue是否显示字数。
showCharCountfalse是否显示字符计数。
countSpacesAsCharsfalse是否将空格计入字符数。
countHTMLfalse是否在字符数中包含 HTML 标签。
maxWordCount-1最大字数限制，-1 表示无限制。
maxCharCount-1最大字符数限制，-1 表示无限制。
filternull计数前的 HTML 过滤规则（htmlParser.filter）。
XfEditor.replace('editor', {
    extraPlugins: 'wordcount',
    wordcount: { showWordCount: true, showCharCount: true, maxCharCount: 2000 }
});
