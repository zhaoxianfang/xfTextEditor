JavaScript API 示例

本页演示如何在页面中通过 JavaScript 操作编辑器：读取 / 写入内容、插入片段、执行命令、 监听事件、导出自包含 HTML。下方按钮均可实时操作上方编辑器，事件日志会同步显示回调结果。

getData / setData insertHtml / insertText execCommand 事件监听 XfEditor 导出辅助

三、XfEditor 辅助对象方法

    
XfEditor 为示例页统一的初始化与导出辅助对象（定义于 examples/js/xf.js）：

    

        
方法参数返回值说明

        
XfEditor.init(id, cfg)id；cfg 覆写配置editor创建编辑器，自动复用 config.full.js 并合并页面配置（extraPlugins 去重）。

        
XfEditor.getHtml(id, opts)opts.standalone/full/titleString读取内容；standalone 返回内联样式片段，full 返回完整文档。

        
XfEditor.exportDocument(id, title)id；title 可选String导出完整自包含 HTML 文档字符串（含 <!DOCTYPE html>）。

        
XfEditor.downloadHtml(id, filename)id；filename 可选—触发浏览器下载为 .html 文件（自包含，离线可用）。

        
XfEditor.getStandaloneCss()—String仅获取内联样式字符串（基础 + 特效）。

        
XfEditor.merge(cfg)cfgObject合并全局配置与页面配置，返回最终配置。

        
XfEditor.getCsrfToken()—String/Null读取页面 csrf-token meta。

    


    
四、编辑器实例（editor）常用方法

    

        
方法说明

        
editor.getData()获取 HTML 内容。

        
editor.setData(html, cb)设置 HTML 内容。

        
editor.insertHtml(html)在光标处插入 HTML。

        
editor.insertText(text)在光标处插入纯文本。

        
editor.execCommand('name')执行命令（如 bold、source、maximize）。

        
editor.focus() / editor.destroy()聚焦 / 销毁实例。

        
editor.on('change', fn)监听内容变化事件。

        
editor.config / editor.name当前配置 / 实例名（元素 id）。

    


    
五、常用代码示例

    
// 取得编辑器实例
var editor = XfEditor.instances.editor;

// 读取 / 写入内容
editor.getData();
editor.setData('<p>新内容</p>');

// 在光标处插入
editor.insertText('纯文本');
editor.insertHtml('<strong>带格式</strong>');

// 执行命令
editor.execCommand('bold');
editor.execCommand('source');   // 切换源码模式

// 事件监听
editor.on('change', function () {
    console.log('内容变化', this.getData());
});
editor.on('instanceReady', function () {
    console.log('编辑器就绪');
});

// 聚焦 / 销毁
editor.focus();
editor.destroy();
