内容导出与预览示例

本页演示把编辑器内容导出为自包含的 HTML：无论保存为 .html 文件还是嵌入任意页面， 都不依赖任何外部 js / css 资源文件即可完整呈现，且展示效果与编辑器内一致。

小技巧：在编辑器中双击任意「文字特效」或「段落特效」（提示框 / 卡片 / 时间轴 / 按钮等）， 即可像双击图片一样弹出编辑窗口，再次修改其内容或样式；也可选中效果后点击工具栏的 「编辑效果」按钮。

导出操作

获取原始 HTMLgetData() 原文 获取自包含片段内联样式，可直接嵌入 实时预览iframe 内渲染完整文档 下载 .html自包含文件，离线可用 复制原始 HTML写入剪贴板 复制自包含 HTML写入剪贴板

实时预览（自包含渲染，与编辑器效果一致）

接口说明

// 原始 HTML（依赖外部 contents.css / 特效样式才完整呈现）
XfEditor.getHtml('editor');

// 自包含片段：内联 <style>，可直接粘贴到任意页面，不依赖外部文件
XfEditor.getHtml('editor', { standalone: true });

// 完整独立 HTML 文档字符串（可保存为 .html 离线打开）
XfEditor.exportDocument('editor', '我的内容');

// 直接触发浏览器下载为 .html 文件
XfEditor.downloadHtml('editor', 'my-content.html');
