代码块编辑示例

pbckcode 插件基于 Ace 编辑器，在对话框中提供带语法高亮的代码编辑， 支持多种语言与主题。

配置项（config.pbckcode）

配置项默认值说明
theme"textmate"Ace 编辑器主题，如 monokai、github 等。
modes内置语言列表对话框中可选的高亮语言（如 php、javascript、python、java 等）。
jscdnjs ace 1.2.6Ace 脚本的 CDN 基础路径。
tabSize4缩进空格数。
highlightActiveLinetrue是否高亮当前行。
CKEDITOR.replace('editor', {
    extraPlugins: 'pbckcode',
    pbckcode: { theme: 'monokai', tabSize: 2 }
});
注意：pbckcode 通过 CDN 加载 Ace 编辑器脚本，内网环境需将脚本下载到本地并修改 js 配置路径。
