表格增强示例

本编辑器在原生表格（table）基础上整合了多项增强能力：

  • quicktable：可视化快速插入网格表格。
  • tableresizerowandcolumn：用鼠标拖拽调整表格行高与列宽。
  • imageresizerowandcolumn：图片随表格行列缩放。

相关配置

CKEDITOR.replace('editor', {
    extraPlugins: 'table,quicktable,tableresizerowandcolumn,imageresizerowandcolumn',
    // 表格单元格、表头、边框等样式在对话框中可配置
});
