PHP 上传接口说明与演示

编辑器通过 CKEditor 的 fileTools / uploadwidget 机制，以 XHR + FormData 上传文件，并要求后端返回统一的 JSON。 本页下方提供了可实时测试的编辑器（需以 PHP 运行环境打开本页）。更完整的参数说明见 php/README.md。

一、接口清单

入口触发方式前端配置项后端脚本（本项目示例）
图片上传图像按钮 / image2 / 拖拽图片filebrowserImageUploadUrlphp/upload_image.php
文件上传上传按钮 / 拖拽或粘贴文件filebrowserUploadUrlphp/upload_file.php

二、通用请求参数

参数名位置类型说明
uploadFormDataFile文件本体，PHP 侧通过 $_FILES['upload'] 读取。
ckCsrfTokenFormDataStringfileTools 自动附加的 CSRF 令牌，用于基础防护。
_tokenURL 查询String业务框架 CSRF Token，由前端从 <meta name="csrf-token"> 读取拼接。
responseTypeURL 查询String固定值 json，约定后端返回 JSON。

三、通用响应结构（HTTP 200 + JSON）

成功

{
  "uploaded": 1,
  "fileName": "2026/07/10/a1b2c3.png",
  "url": "https://你的域名/uploads/2026/07/10/a1b2c3.png"
}

失败

{
  "uploaded": 0,
  "error": { "message": "文件类型不被允许" }
}
字段必填说明
uploaded是1=成功，0=失败，这是前端唯一判定依据。
url成功时必填上传后文件的可访问完整 URL（或 / 开头的相对路径）。
fileName否展示用文件名。
error.message失败时必填可读的错误原因，将展示给用户。

四、实时上传演示

下方编辑器已配置为上传到 php/upload_image.php 与 php/upload_file.php。请拖拽一张图片或一个文件到编辑区，或点击 图片 / 上传按钮进行测试（需以 PHP 服务运行本页）。

五、前端配置示例

CKEDITOR.replace('editorPhp', {
    language: 'zh-cn',
    extraPlugins: 'uploadfile,image2,divarea,filetools',
    // 指向本项目提供的 PHP 示例接口（相对路径）
    filebrowserImageUploadUrl: '../php/upload_image.php',
    filebrowserUploadUrl: '../php/upload_file.php',
    editorplaceholder: '试试拖拽图片或文件到此处上传……'
});
注意：php/ 目录下的示例脚本使用原生 PHP 编写， 默认将文件保存到 php/../public/uploads 目录，并将 $baseUrl 指向 https://cdn.example.com/uploads。请按实际部署环境修改这两个变量，详见 php/README.md 第 9 节完整示例与第 10 节安全最佳实践。
